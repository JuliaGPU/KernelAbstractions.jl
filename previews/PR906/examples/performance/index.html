Settings

This document was generated with Documenter.jl version 1.19.0 on Tuesday 27 October 2026. Using Julia version 1.13.3.

@Const(A)

@Const is an argument annotiation that asserts that the memory reference by A is both not written to as part of the kernel and that it does not alias any other memory in the kernel.

@groupsize()

Query the workgroupsize on the backend.

@index

The @index macro can be used to give you the index of a workitem within a kernel function.

@kernel function f(args) end @kernel config function f(args) end

Takes a function definition and generates a Kernel constructor from it.

@localmem T dims

Declare storage that is local to a workgroup.

@synchronize() @synchronize(cond)

After a @synchronize statement all read and writes to global and local memory from each thread in the workgroup are visible in from all other threads in the workgroup.

@uniform expr

Evaluate expr on every work-item of the workgroup, including padding work-items that fall outside of the ndrange.

allocate(::Backend, Type, dims...; unified=false)::AbstractArray

Allocate an uninitialized array on the active device of the backend.

synchronize(::Backend)

Block the calling task until all work it has queued on the active device of backend has completed.

allocate(::Backend, Type, dims...; unified=false)::AbstractArray

Allocate an uninitialized array on the active device of the backend.

synchronize(::Backend)
